# ZikeQuote3 语录插件隐私政策

**最后更新日期:** 2025-10-07

旨在增添群内的活跃度与趣味性，本群启用了基于 NoneBot2 的 ZikeQuote3 语录插件（下称“本插件”）。本插件会自动或手动收集群聊中的精彩发言作为“语录”，供大家娱乐和回顾。

本插件开发者希望共同维护大家的隐私安全。因此这份文件将向你说明，本插件会如何收集、使用和保护你的信息。

## 1. 本插件收集什么信息？

为了实现语录功能，本插件会处理以下信息：

- **群聊消息内容**：你发送的文本、图片等消息，这是筛选语录的基础。
- **你的基本身份信息**：你的 QQ 号、群昵称和头像，用于将语录与你关联起来。

## 2. 本插件为什么收集和处理信息？

我们收集和处理信息的**唯一目的**是：

- **筛选和收录语录**：通过自动（LLM分析）或手动方式，将有趣的群聊片段保存下来。
- **展示和查询语录**：用于生成语录排行榜、随机语录、语录卡片等功能，增加群聊的趣味性。
- **生成一部分语录的统计信息**：计算用于丰富群聊语录功能的其它统计信息

我们承诺，绝不会将收集到的信息用于语录功能之外的任何其他目的。

## 3. 信息如何被插件和第三方处理？

1. **收集**：本插件在群聊中持续收集消息。
2. **分析**：当满足特定条件时（例如消息达到一定数量），机器人会将**近期的一段聊天记录**发送给一个大型语言模型（LLM）进行分析，以判断其中是否包含值得收录的语录。
    - **根据管理员配置，可能会使用第三方的大语言模型服务商，或是本地部署的大语言模型。**
    - **隐私保护措施**：在将消息发送给 LLM 前，我们已在机器人代码层面采取**脱敏措施**，QQ 号已经被用一个无法反推个人信息的消息 ID 代替，LLM 提供商仅能得知群名片与消息 ID，无法得知消息发出者的 QQ 号及身份信息。
3. **存储**：经由LLM筛选或管理员手动确认后，被选中的语录（包含你的 QQ 号和昵称）将被保存在插件管理员的数据库中。
    - **数据库位置**：数据库位于管理员启用 Nonebot 的计算机上，储存 Nonebot2 插件的数据目录。

## 4. 您的权利与控制选项

我们充分尊重你对自己信息的控制权，并为你提供了以下命令来行使你的权利：

- **知情权**：你可以随时使用 `/语录隐私政策` 命令查看本政策。
- **访问权**：使用 `/语录列表` 或 `/语录列表 @你` 等命令来查看所有被收录的、关于你的语录。
- **删除权**：
  - 使用 `/删语录 [语录ID]` 可以删除关于你的单条语录。
- **拒绝/退出权**：
  - 如果你不希望你的任何发言被本插件自动收集和分析，请使用 `/停用语录` 命令。执行后，你的任何消息都不会被用于 LLM 分析，且现有的所有信息都将从数据库中删除。可以使用 `/重启语录` 命令重新启用，但重新启用前的数据将无法恢复。

## 5. 数据安全与存储期限

开发者将、管理员应：尽其所能保护存储语录的数据库安全，防止数据泄露。

- **存储期限**：语录将被永久保存在对应位置，直到其被修改或删除。
